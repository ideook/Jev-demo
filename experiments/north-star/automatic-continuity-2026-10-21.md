## Automatic behavior

- The first human request is journaled locally with original record hashes and
  offsets before any API call. A literal provisional goal is immediately active.
  Codex privately refines scope, constraints, milestones and results using the
  existing versioned anchor CLI. The user does not maintain this ledger.
- Structured approval replies cannot replace an available original task at
  bootstrap. Resume/compaction preserves goals and pending recovery. A native
  temporary transcript projection is replaced only by a canonical original
  rollout with matching thread identity under configured roots.
- PostToolUse covers local tool types without a Bash-only matcher. Jev sees
  assistant intent and bounded conversational evidence. Tool bodies and output
  stay local. Codex must check actual operations, particularly writes.
- Strong drift requests immediate private recovery; Stop can request one bounded
  continuation. Explicit human pivots and returns are respected. Uncertainty or
  unavailable evaluation requests one local scope/effect check per status, goal
  version and 15-minute cooldown, without pretending to detect drift.
- Aligned intent plus an observed explicit successful tool result can close the
  recovery ledger. If Jev abstains, Codex can instead acknowledge verified local
  effects using `review_recovery` in a versioned anchor patch. This requires the
  same goal, current version, pending observation hash, completed claims and an
  original assistant result ref matching the successful execution observation.
  Its status is `agent_reviewed_execution`, not a Jev verdict or proof that the
  parent task is complete.
- One shared budget permits at most 24 requests/thread/hour, with an 8-second
  network timeout, no HTTP retry, 60-second failure backoff, unchanged-intent
  cache and 15-minute notice cooldown. Provider failure, missing key/source,
  clipped evidence, budget exhaustion and stale responses remain distinct.

The automatic module is [automatic.py](../../hooks/north-star/automatic.py),
and operating instructions are in [SKILL.md](../../skills/north-star/SKILL.md).
Fixed evaluator instructions are authored directly in English. Original human
text remains original; there is no translation API stage.

## Live history evaluation

The user explicitly approved **23 deidentified cases, at most 24 paid calls**
to `https://api.typesafe.ai/v1/systemone`. Only selected goals/work excerpts were
sent. Full logs, source files and tool bodies were excluded. Nested historical
secret blocks were discovered during preparation; redaction was expanded before
external evaluation. Arbitrary personal names cannot be perfectly identified.

The sealed set contains **22 chronological history pairs and one explicitly
counterfactual recombination**. Later corrections informed case interpretation
but were not inserted as if they preceded the original observation. H16 combines
a later root-cause request with an earlier retry-result report; it is not proof
of a historically detectable pre-intervention drift event.

[automatic_evaluation.py](automatic_evaluation.py) automatically registered a
goal for all 23 cases without an agent anchor command. There were exactly
**24 API requests**, all reporting `jev-1.14.0`. API round-trip median was
**265 ms**, maximum **391 ms**, excluding native shell startup and Codex review.

- Of the 22 chronological pairs, **19 were confidently aligned and 3 abstained**
  (H02, H08 and H18). No strong recovery request was issued. Abstention is not
  counted as successful classification.
- H16 also **abstained**, so the intended counterfactual drift was missed.
  Its later aligned continuation did not establish recovery because none had
  been requested. This is recorded as a miss, not a passing recovery test.
- With identical saved request hashes and no new API calls, final-policy replay
  routes all four abstentions to bounded private local checks. This improves
  coverage of uncertainty; it does not convert them into detected errors or
  prove that an agent would make the right correction.

The 19/23 expectation matches are a development-set observation, **not measured
accuracy**. This small, selected sample cannot establish drift recall, especially
for wrong implementation hidden behind plausible commentary.
